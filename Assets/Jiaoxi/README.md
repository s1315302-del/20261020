# 礁溪溫泉公園

開啟 `Assets/Jiaoxi/JiaoxiOnsen.unity`，按 Play。

- A / 左方向鍵：左煞車注入冷水；D / 右方向鍵：油門注入熱水。
- 手把 LT / RT：類比控制冷水 / 熱水力道。
- 90 秒內完成三階段：38–42°C 維持 5 秒、39–42°C 維持 7 秒、40–42°C 維持 9 秒。
- 維持冷熱合計注水力道至少 55%；離開綠區或注水不足會重計該階段。
- 山風、地熱與泉壓會改變溫度，水溫有慣性。注意右上角的擾動與趨勢，提早修正。
- 低於 25°C 或高於 55°C 持續 3 秒，或時間耗盡，即挑戰失敗。
- R：重新遊玩。

以上溫度為遊戲數值。Inspector 可調整 timeLimit；各階段範圍與秒數由 JiaoxiOnsen.SetRound 設定。

實體踏板：由硬體輸入程式每幀呼叫 JiaoxiOnsen.SetPedals(leftBrake, accelerator)，兩個參數皆為 0–1，放開為 0、踩到底為 1。ReleasePedals() 可切回鍵盤 / 手把。實際 HID 軸與校正需依方向盤型號接線。

場景包含森林、遠山、竹林、杜鵑花叢、溪流、木橋、鳥居、茶屋、石步道、石造泡腳池、木平台、日式亭、燈籠、霧氣與蒸氣粒子。Jiaoxi/Build Onsen Scene 可重建獨立場景，會取代目前開啟場景，請先儲存自己的變更。

已驗證：加熱、注水不足重計、離開綠區重計、倒數失敗、極端水溫失敗、重玩，以及包含力道延遲的鍵盤控制模擬完成三階段。Unity Play Mode 無遊戲錯誤。尚未以實體踏板或實體手把驗證輸入。
